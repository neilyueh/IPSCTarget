# IPSC 靶監看

在另一台電腦上即時看 IPSC 電子靶（GR-WOLF FlexTarget）的命中結果，不用走到靶前面，還能從電腦遠端控制靶機。

## 功能

- 畫出和靶機相同的 IPSC 靶，依序標出第 1、2、3… 發的位置，最新一發紅色
- 每一發的分區（A / C / D / Miss）、分段時間、座標
- 統計：彈數、最快與平均分段、各區數量
- **和靶機同步清除**：對靶上的 RESET 開一槍，或在手機 App 按 RESET，頁面自動清空（那一槍不算成績）
- **遠端控制靶機**（藍牙）：◀ 上一靶／◎ 清除／▶ 下一靶／↩ 返回／⌂ 首頁／⟳ 重新連接藍牙，按下去靶機畫面直接動；每送出一個指令，頁面紀錄也會跟著清空
- 打開時自動連上靶機；IP 變了會自動在同網段搜尋，也可按「重新搜尋」
- 可選：停頓超過 N 秒自動開新一輪、命中提示音
- 鍵盤：按 `C` 或空白鍵只清電腦紀錄

## 使用方式

1. 電腦和靶機連同一個 Wi-Fi（收命中資料用）。
2. 用 **Chrome 或 Edge** 打開 [`monitor/index.html`](monitor/index.html)（直接開檔案即可；若藍牙按鈕沒反應，改用 `python3 -m http.server` 開 `http://localhost:8000`）。
3. 左上角顯示綠點「已連線」就可以開始打。
4. 「靶機縮放」要和靶機畫面下方的 Zoom 一致，A/C/D 判定才會準。
5. 要遠端控制：按「連接靶機」（或直接按任一控制鍵），在跳出的裝置清單選 **GR-WOLF ET …**，允許藍牙權限即可（macOS 第一次會要求在「系統設定 → 隱私權與安全性 → 藍牙」允許 Chrome）。控制走藍牙，和 Wi-Fi 連線互相獨立。重新整理頁面後要再選一次裝置。

## 運作原理

### 命中資料（WebSocket）

靶機在區網開放 `ws://<靶機IP>/websocket`，每次命中會廣播：

```json
{"type":"data","data":[{"t":497201,"x":143.0,"y":254.0,"a":1427}]}
```

- `x`、`y`：命中位置，單位公釐，範圍約 268 × 476.4（21.5 吋直立螢幕），原點在左下
- `t`：毫秒時間戳，用來算分段

頁面把座標換算到靶機的 720 × 1280 畫面，再用靶機自己的 IPSC 分區形狀判斷 A/C/D。
手機 App 的按鍵也會以 `{"type":"control","directive":"enter"}` 等格式廣播，頁面據此同步清除。

### 遠端控制（藍牙 BLE）

WebSocket 通道**不會**轉發電腦送出的指令（靶機伺服器只把它當監看用），UDP mesh（port 19090）在韌體上也沒開。實際可用的控制通道是 **BLE**，和手機 App 按控制鍵走同一條路：

1. 掃描並連接裝置名 `GR-WOLF ET …`（也可 `GRWOLF-` 前綴）
2. 服務 `0000ffc9-…`，指令寫入特徵 **FFE2**，回應在 **FFE1**（notify）
3. 指令為一行 JSON（結尾 `\r\n`）：

```json
{"action":"remote_control","directive":"left"}
```

常見 `directive`（依靶機當前畫面而定）：

| directive | 練習畫面（Bootcamp） | 主選單 |
|---|---|---|
| `left` / `right` | 上一靶 / 下一靶 | 移動選取 |
| `enter` | 清除（RESET） | 確認選取 |
| `back` / `homepage` | 都是回主選單 | 回上一層 / 回主選單 |

靶機回 `{"type":"notice","action":"remote_control","state":"success",…}` 表示已受理。
遊戲端對**同一個** directive 有 0.5 秒節流，頁面發送端也做了 0.6 秒節流。
其他通道（供參考）：REST API（`/system/volume/increase`、`/game/start`、`/netlink/status` 等）、
`{"action":"forward","content":{"command":"query_version"}}` 可查韌體版本（目前 1.0.7）。

## 限制

- 頁面上的「只清電腦紀錄」只清這台電腦；要連靶機一起清，用「遠端控制」的 ◎ 清除，或對 RESET 開槍。
- 遠端控制需要 Chrome/Edge（Web Bluetooth），且電腦要和靶機在藍牙範圍內（約 10 公尺）。
- 開機自動進入 IPSC 紙靶目前做不到（可用遠端控制手動導航，但沒有狀態回饋）。
- 只會在跟電腦同一網段內找靶機。
