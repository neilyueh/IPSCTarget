# IPSC 靶監看

在另一台電腦上即時看 IPSC 電子靶（GR-WOLF FlexTarget）的命中結果，不用走到靶前面；支援**同時連多台靶機**、統計成績，還能從電腦遠端控制靶機。

📄 圖文使用說明：[`docs/IPSC靶監看-使用說明.pdf`](docs/IPSC靶監看-使用說明.pdf)

## 功能

**多台靶機**
- 打開時連上清單裡所有靶機，並在背景搜尋同網段，找到新的靶機自動加入
- 「搜尋靶機」可手動重新搜尋；也可在右下「手動加入 IP」，或按靶卡上的 ✕ 移除
- 每台靶機一張靶卡：名稱（點一下可改）、IP、連線狀態、彈數與分數；⤢ 可放大單張靶
- 一排最多 3 張靶卡，超過就往下排、用滑鼠滾輪上下捲動；右側成績欄捲動時固定在畫面上（視窗較窄時一排 2 張，手機寬度一排 1 張）
- 清單、名稱、每台的縮放設定都會記住

**換靶（和靶機畫面一樣）**
- 靶圖用的是靶機程式裡的原圖，位置、大小、縮放都照靶機設定，所以和靶機螢幕上看起來一樣
- 靶卡上方的 ◀ ▶ 依靶機順序切換全部 17 種靶：靶心、IPSC 紙靶、Hard cover 1、Hard cover 2、人質靶、IPSC 雙靶、2 個 Popper、3 個 Paddle、USPSA、IDPA、IDPA NS、IDPA 硬遮蔽 1、2、Mozambique、自訂靶、決鬥樹、德州星
- 有連藍牙時，◀ ▶ 就是按靶機的 ◀ ▶，靶機和網頁一起換；沒連藍牙時只換網頁
- **靶清單**：只有一台靶機（或按 ⤢ 放大）時，靶圖右邊列出全部 17 種靶，綠框是目前的靶、藍框是按 ◀ 會換到的、橘框是按 ▶ 會換到的，清單會自動捲到目前的靶；多台時改成在 ◀ ▶ 旁邊各放一張小圖
- 點清單裡任一張靶就切換過去：有連藍牙時網頁自動連按 ◀ 或 ▶（走最短的方向，每按一次約 0.7 秒），靶機一起換；沒連藍牙時只換網頁
- 在手機 App 換靶、或對靶機畫面上的 ◀ ▶ 開槍，網頁會跟著換
- 「校正」：靶機畫面和網頁不一樣時，選靶機目前顯示的靶（不會送指令給靶機）；校正會清掉那一台目前的紀錄。網頁每次連上靶機時會提醒確認一次（靶種正確的話點提醒就會關閉）
- 靶機回主選單時（網頁的 ⌂、手機 App、或命中畫面上的 ⌂），網頁會把靶設成「靶心」並提示，因為重新進入練習畫面時靶機一定從靶心開始
- 每台靶機目前的靶種會記住
- 計分支援 IPSC 紙靶、Hard cover 1、Hard cover 2、人質靶、IPSC 雙靶；其他靶只顯示命中位置與順序
- IPSC 雙靶是上下兩張紙靶，照靶機規則先判前面（下方）那張、再判後面（上方）那張，射擊順序表會標示 A（下）、A（上）；比賽模式每張各取最佳 2 發
- 無法完全一樣的：自訂靶（你上傳的圖片網頁拿不到，顯示問號）、德州星與決鬥樹（只畫靜止的樣子）、Popper / Paddle 的倒下動畫

**命中與成績**
- 每張靶卡畫出和靶機畫面相同的靶，依序標出第 1、2、3… 發，全場最新一發紅色
- 成績總表：每台的彈數、A / C / D / Miss、分數，以及合計
- 全場統計：總彈數、總分、時間、Hit Factor
- 射擊順序：依時間列出每一發打在哪台（第幾發）、哪一區、分段；換靶的那一發標 ↪
- 計分可選 **練習**（每發都算）或 **比賽**（每張靶取最佳 2 發，不足 2 發算 Miss），以及 **Minor**（A5 / C3 / D1）或 **Major**（A5 / C4 / D2）；Miss 扣 10 分
- 打在黑色遮蔽區 0 分（表格算在 Miss 欄，和靶機一樣）；打到人質每發扣 10 分，穿過人質又打到靶時兩者都算（例如 A +5、人質 -10），成績表有 NS 欄

**清除**
- **全部清除**：透過藍牙對每台已連接的靶機送出清除，並清空電腦紀錄；沒連藍牙的靶機只清電腦紀錄，會提示幾台
- 靶卡上的 ◎ 清除：只清那一台（靶機＋電腦）
- 對某台的 RESET 開一槍，或在手機 App 按 RESET，那台的紀錄自動清空（那一槍不算成績）；可勾選「任一台 RESET 就全部清除」
- 「只清電腦紀錄」、鍵盤 `C` 或空白鍵：只清電腦上的紀錄

**遠端控制（藍牙）**
- 每張靶卡各自連藍牙（靶卡下方的「藍牙」），連上後：
  - 靶卡上方的 ◀ ▶、靶清單：靶機一起換靶
  - ◎ 清除：清除那台的彈孔和紀錄
  - ⌂：靶機回主選單
  - **進靶畫面**：先送「回主選單」，1.5 秒後再送「確認」，讓靶機從主選單進入靶畫面。「確認」會選主選單上目前反白的項目，請看靶機螢幕確認進對；進入練習畫面後靶機從「靶心」開始，要用紙靶再按 ▶
- 送出的指令靶機受理後，靶卡下方會顯示「指令成功 ✓」

**其他**
- **🎤 語音**：上方的開關打開後（按鈕變綠）網頁持續聆聽，說「**重來**」（也接受「重新開始」「重新來」「重來一次」）就和按「全部清除」一樣：用藍牙清除每台已連藍牙的靶機，並清空電腦紀錄。3 秒內重複說只算一次；上方會顯示最後聽到的字。使用 Chrome / Edge 內建的語音辨識，**語音會由瀏覽器送到 Google 辨識，需要網路**；第一次會要求麥克風權限（直接開檔案若不允許，改用 `python3 -m http.server` 開 `http://localhost:8000/monitor/`）
- **🖱 模擬射擊**：上方的開關打開後（按鈕變藍），在網頁的靶圖上點一下就當成那裡中了一發，用來不開槍測試計分、射擊順序和清除；射擊順序會標「（模擬）」。只在網頁上模擬，不會傳到靶機，靶機螢幕不會出現彈孔。點靶圖上的 RESET 框會清除紀錄；點 ◀ ▶ ⌂ 框不會換靶（靶機收不到，會對不上），要換靶請用靶卡上方的 ◀ ▶。模擬的發和真的命中混在一起時分段會不準，測完先清除再正式打
- 可選：停頓超過 N 秒自動開新一輪、命中提示音

## 使用方式

1. 電腦和靶機連同一個 Wi-Fi（收命中資料用）。
2. 用 **Chrome 或 Edge** 打開 [`monitor/index.html`](monitor/index.html)（直接開檔案即可。要拿到別台電腦用時，複製整個 `monitor` 資料夾：`index.html` 和放靶圖的 `target-images.js` 要放在一起；若藍牙按鈕沒反應，改用 `python3 -m http.server` 開 `http://localhost:8000`）。
3. 頁面會連上記住的靶機，並自動搜尋同網段的其他靶機。左上角顯示「已連線 N/N 台」就可以開始打。
4. 每張靶卡的縮放要和那台靶機畫面下方的 Zoom 一致，A/C/D 判定才會準。
5. 建議把每台靶機的名稱改成好認的（例如「左」「中」「右」），並在路由器替每台固定 IP；頁面靠 IP 分辨靶機。
6. 要遠端控制：按靶卡上的「藍牙」（或直接按任一控制鍵），在跳出的裝置清單選**那一台**對應的 **GR-WOLF ET …**，允許藍牙權限即可（macOS 第一次會要求在「系統設定 → 隱私權與安全性 → 藍牙」允許 Chrome）。控制走藍牙，和 Wi-Fi 連線互相獨立。重新整理頁面後要再選一次裝置。

## 運作原理

### 命中資料（WebSocket）

靶機在區網開放 `ws://<靶機IP>/websocket`，每次命中會廣播：

```json
{"type":"data","data":[{"t":497201,"x":143.0,"y":254.0,"a":1427}]}
```

- `x`、`y`：命中位置，單位公釐，範圍約 268 × 476.4（21.5 吋直立螢幕），原點在左下
- `t`：毫秒時間戳，用來算分段

頁面把座標換算到靶機的 720 × 1280 畫面，再用靶機自己的 IPSC 分區形狀判斷 A/C/D。
手機 App 的按鍵也會以 `{"type":"control","directive":"enter"}` 等格式廣播，頁面據此同步清除。

每台靶機各自有 Wi-Fi IP 和自己的 WebSocket，頁面對每台各開一條連線，所以不依賴靶機之間的 netlink（master / slave）連線。

### 搜尋靶機

1. 先對網段內每個位址發一般的 HTTP 請求，找出有網頁伺服器的機器（Chrome 會刻意拖慢連續失敗的 WebSocket 連線，一般請求不會）。
2. 只對有回應的幾台試 `ws://<IP>/websocket`，能連上的就是靶機。
3. 先搜清單裡靶機所在的網段；清單是空的才試常見的家用網段（192.168.1.x、192.168.0.x 等）。

### 靶種同步

靶機不會回報目前顯示哪個靶，所以網頁自己記：練習畫面的靶依固定順序循環（共 17 種），網頁每看到一次 ◀ / ▶ 就往前或往後一格。

遊戲本身就是從 WebSocket 收到每一個指令（不論來自手機 App 或網頁的藍牙），所以網頁**只以 WebSocket 上的指令為準**：網頁用藍牙送出 ◀ / ▶ 後，不會自己先換，而是等靶機把指令廣播回來才換，避免同一次切換被算兩次。沒有 WebSocket 連線、或 1.5 秒內沒收到廣播時，才直接套用。網頁也和遊戲一樣，對同一個指令 0.5 秒內只算一次。命中靶機畫面上的 ◀ ▶ 按鈕則從命中座標判斷。

### 靶圖

`monitor/target-images.js` 收錄靶機程式裡的靶圖（GR-WOLF 的素材，請只自用、不要公開），每種靶的圖片位置與縮放取自靶機的場景檔，畫面以 720 × 1280 裁切，和靶機螢幕相同。德州星依靶機程式的畫法重建（中心、7 根桿、桿端鋼板）。少了這個檔案時，計分的紙靶會改畫分區線框。

五種計分紙靶的分區形狀都取自靶機程式，計分優先順序也一樣：A > C > D，其次遮蔽區；打到人質另外扣分。

### 計時與分段

- 同一台的連續兩發：用靶機自己的時間戳計算，最準。
- 換到另一台的那一發：各台靶機的時鐘不同步，改用電腦收到訊息的時間，會有一點網路延遲誤差。
- 「時間」= 第一發到最後一發，不含起始嗶聲與拔槍，所以 Hit Factor 會比實際比賽偏高。

### 遠端控制（藍牙 BLE）

WebSocket 通道**不會**轉發電腦送出的指令（靶機伺服器只把它當監看用），UDP mesh（port 19090）在韌體上也沒開。實際可用的控制通道是 **BLE**，和手機 App 按控制鍵走同一條路：

1. 掃描並連接裝置名 `GR-WOLF ET …`（也可 `GRWOLF-` 前綴）
2. 服務 `0000ffc9-…`，指令寫入特徵 **FFE2**，回應在 **FFE1**（notify）
3. 指令為一行 JSON（結尾 `\r\n`）：

```json
{"action":"remote_control","directive":"left"}
```

常見 `directive`（依靶機當前畫面而定）：

| directive | 練習畫面（Bootcamp） | 主選單 |
|---|---|---|
| `left` / `right` | 上一靶 / 下一靶 | 移動選取 |
| `enter` | 清除（RESET） | 確認選取 |
| `back` / `homepage` | 都是回主選單 | 回上一層 / 回主選單 |

靶機回 `{"type":"notice","action":"remote_control","state":"success",…}` 表示已受理。
遊戲端對**同一個** directive 有 0.5 秒節流，頁面發送端也做了 0.6 秒節流。
其他通道（供參考）：REST API（`/system/volume/increase`、`/game/start`、`/netlink/status` 等）、
`{"action":"forward","content":{"command":"query_version"}}` 可查韌體版本（目前 1.0.7）。

## 限制

- 「只清電腦紀錄」只清這台電腦；要連靶機一起清，用「全部清除」或靶卡上的 ◎ 清除（需藍牙），或對 RESET 開槍。
- 遠端控制需要 Chrome/Edge（Web Bluetooth），且電腦要和靶機在藍牙範圍內（約 10 公尺）。
- 網頁讀不到靶機的名稱（靶機的狀態介面不允許網頁讀取），所以只能用 IP 分辨；藍牙裝置要自己選對哪一台。
- 多台同時使用目前只用模擬資料測過（家裡現在只有一台靶機）。
- 靶種同步是網頁自己推算的：網頁打開前就在靶機上換過靶，或直接在靶機上進出畫面時可能對不上，要按「校正」。
- 開機自動進入 IPSC 紙靶做不到；開機後可用靶卡的「進靶畫面」再按 ▶ 切到紙靶（需藍牙，主選單的反白位置要對）。
- 網頁沒辦法讓靶機本身產生一發命中（命中只來自靶機內部的感測器，WebSocket、藍牙、HTTP 都沒有這種指令）；「模擬射擊」只在網頁上。
- 校正會清掉那一台目前的紀錄。
- 只會在跟電腦同一網段內找靶機。
- 計時不含起始嗶聲，Hit Factor 僅供參考。
